# 计费、余额与使用记录

余额用于按调用消耗；订阅或套餐按站内规则提供额度和权限。实际以站内仪表盘、订单和使用记录为准。

## 充值与兑换

如果从发卡网购买兑换码：

1. 在右上角点击 **充值商城**。
2. 如果弹出渠道选择，优先点主卡网；主卡网打不开再用备用卡网。
3. 在发卡网购买商品，付款后复制兑换码/卡密。
4. 回到站内左侧 **兑换** 页面，粘贴兑换码并点击 **兑换**。

![充值商城入口](/images/subapi/09-recharge-storefront-entry.png)

![兑换页面](/images/subapi/02-redeem-code-page.png)

如果站内直接充值或购买订阅：

1. 点击左侧 **充值/订阅**。
2. 在 **充值** 里选择金额，或输入自定义金额。
3. 选择支付方式，例如支付宝、USDT、USDT-BSC。
4. 完成支付后回到仪表盘看余额，或到 **我的订单** 看订单状态。

![充值订阅页面](/images/subapi/03-recharge-subscription-page.png)

![订单页面](/images/subapi/05-orders-page.png)

## 订单状态

| 状态 | 含义 |
| --- | --- |
| 待支付 | 订单已创建，还没检测到付款 |
| 已完成 | 付款确认并入账 |
| 失败/超时 | 订单未成功，可以重新下单或联系售后 |

## 使用记录

使用记录是判断请求是否命中 subapi 的最好证据。

建议不同客户端使用不同 Key：

- 方便看每个客户端消耗。
- 方便单独限额。
- 某个客户端异常时，可以只禁用对应 Key。
