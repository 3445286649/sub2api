# 计费、余额与使用记录

余额用于按调用消耗；订阅或套餐按站内规则提供额度和权限。实际以站内仪表盘、订单和使用记录为准。

## 充值与兑换

### 站内直接充值

1. 点击左侧 **充值**。
2. 在 **充值** 里选择金额，或输入自定义金额。
3. 选择支付方式，例如支付宝、USDT、USDT-BSC。
4. 完成支付后回到仪表盘看余额，或到 **我的订单** 看订单状态。

![充值订阅页面](/images/subapi/03-recharge-subscription-page.png)

![订单页面](/images/subapi/05-orders-page.png)

### 卡密充值（发卡网购买）

支付方式不方便时，可以在发卡网买卡密再兑换：

1. 点击右上角 **充值商城**，会打开 **充值** 页的 **卡密充值** 标签。
2. 在页面下方的商城里选商品购买，付款后复制发货的卡密。
3. 粘贴到页面上方的输入框，点击 **兑换**。

![卡密充值](/images/subapi/09-recharge-storefront-entry.png)

商城加载不出来时，点商城右上角的 **外部打开**，在新窗口里购买。

### 已有兑换码

左侧 **兑换**，粘贴兑换码并点击 **兑换**。兑换码区分大小写。

![兑换页面](/images/subapi/02-redeem-code-page.png)

## 订单状态

| 状态 | 含义 |
| --- | --- |
| 待支付 | 订单已创建，还没检测到付款 |
| 已完成 | 付款确认并入账 |
| 失败/超时/已取消 | 订单未成功，可以重新下单或联系售后 |

实际状态名以 **我的订单** 页面显示为准。

## 不登录查 Key 用量

[API Key 用量查询](https://codeplan.codes/key-usage) 页面不用登录，粘贴 API Key 就能看这个 Key 的消费金额和使用状态。Key 只在浏览器本地处理，不会被保存。适合把 Key 发给同事用时，让对方自己查余量。

![API Key 用量查询](/images/subapi/key-usage-page.png)

想在桌面上常驻显示余额，见 [余额悬浮窗](/balance-float)。

## 使用记录

[使用记录](https://codeplan.codes/usage) 是判断请求有没有真正走 CodePlan 的最好证据：客户端能回复但这里没有记录，说明请求走了别的地方，见 [排查](/troubleshooting#能回复但没有使用记录)。

建议不同客户端使用不同 Key：

- 方便看每个客户端消耗。
- 方便单独限额。
- 某个客户端异常时，可以只禁用对应 Key。
