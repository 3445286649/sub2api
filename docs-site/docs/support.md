## 提问前先准备

把下面这些一次发全，能省掉来回询问的时间：

- **现象**：具体报错文本或截图（比如 `401`、`model not found`）。
- **客户端**：用的是 Codex、Claude Code、VS Code 插件还是 CCSwitch。
- **Key 名称**：只发名称，**不要发完整 Key**。
- **使用记录**：站内 [使用记录](https://codeplan.codes/usage) 的截图，能看出请求有没有到达本站。
- **订单问题**：订单号或支付截图，敏感信息打码。

::: danger 保护 API Key
完整 API Key 等同于你的消费凭证。任何人（包括自称客服的人）索要完整 Key 都不要给。
:::

先自查可以看 [常见报错排查](/troubleshooting)，大部分问题能在那里直接解决。
