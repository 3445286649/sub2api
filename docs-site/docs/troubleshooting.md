# 常见报错排查

先按这张表定位问题：

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| `401` / `Unauthorized` | Key 不完整、前后有空格、Key 被删除或禁用 | 重新复制 Key，必要时新建 Key |
| 余额不足 | 余额、订阅额度或 Key 限额不足 | 查看仪表盘余额、订阅和 Key 限额 |
| `model not found` | 模型不在 Key 绑定分组里，或客户端模型名写错 | 换模型名或调整 Key 分组 |
| CCSwitch 导入失败 | 浏览器未识别协议、CCSwitch 未安装或未打开 | 用 Google Chrome 打开站点，重启 CCSwitch 后再导入 |
| 导入成功但不生效 | CCSwitch 当前使用的不是 `loucer_api` | 在 CCSwitch 中点击启用，直到显示 **使用中** |
| 站内无使用记录 | 请求没打到 subapi | 检查 Base URL、Provider 和客户端登录模式 |

## 建议排查顺序

1. 先确认站内余额或订阅。
2. 确认 API Key 存在、启用、绑定了正确分组。
3. 确认客户端 Base URL 和 Key。
4. 发起一次测试请求后看 **使用记录**。

## CCSwitch 特别注意

CCSwitch 可以同时保存很多配置。真正生效的是显示 **使用中** 的那一条。如果当前使用的不是 `loucer_api`，请求可能会走到别的站点或别的 Key。

## 问售后时建议提供

- 订单号或支付截图，敏感信息打码。
- API Key 名称，不要发完整 Key。
- 客户端名称和配置截图。
- 站内使用记录截图或具体报错文本。
